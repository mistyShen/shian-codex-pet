## 使用原则

- 生成主形象时优先使用 `shian_front_pose.png`、`shian_main_pose.png` 和 `shian_reference_board.png`。
- 生成动作时用 `shian_action_states.png` 和对应 `state_*.png` 表达动作语义。
- 单状态裁切来自一张密集设定板，只作为动作语义参考；角色一致性以三视图和正面图为准。
